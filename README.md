# 🔐 Реферальный бот Telegram (выдача доступа по postback)

Бот-привратник: впускает в приватную группу только тех, кто выполнил условие
в партнёрской системе. Всё автоматически, без ручной проверки.

**Схема работы:**

```
Реферальная ссылка → пользователь → действие в партнёрке
        → postback → бот проверяет → одноразовая ссылка в группу
```

**Что умеет:**
- По ссылке с уникальным кодом (`t.me/бот?start=КОД`) запоминает пару «код ↔ пользователь»
- Принимает postback от партнёрской системы через встроенный HTTP-сервер
- Выдаёт **одноразовую** ссылку-приглашение: ссылка работает для одного человека
- Защита от повторной выдачи — каждая выдача фиксируется в базе, дубль не пройдёт
- Ручная выдача админом командой `/grant` (если postback потерялся)
- Целевая группа задаётся командой `/setgroup` прямо в чате группы — без правки конфигов
- Опциональный секрет в postback — защита от подделки заявок
- Хранение в SQLite — один файл, никаких внешних сервисов
- Токен и настройки — в `.env`, в коде их нет

## Логика базы — проверена тестами

`test_local.py` проверяет без сети: сохранение пары, блокировку повторной

## Как запустить (для не-программиста)

### Шаг 1. Создай бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя (username должен заканчиваться на `bot`).
2. Скопируй **токен** из ответа (`1234567890:AAE3f...`) — никому его не показывай.

### Шаг 2. Узнай свой Telegram-ID
Напиши боту **@userinfobot** — он ответит твоим `Id` (число вида `123456789`).

### Шаг 3. Настрой и запусти
```bash
git clone https://github.com/ZolotarevMikhail/telegram-referal-bot.git
cd telegram-referal-bot
pip install -r requirements.txt
cp .env.example .env    # на Windows: copy
```

Открой `.env` и заполни:
```
BOT_TOKEN=токен_из_BotFather
ADMIN_IDS=твой_ID
STATUS_OK=1
POSTBACK_PORT=8000
POSTBACK_SECRET=
```

```bash
python bot.py
```

### Шаг 4. Подключи группу
1. Добавь бота в свою группу и сделай его **администратором** (право приглашать участников).
2. Внутри группы отправь `/setgroup` — бот запомнит целевую группу.

### Шаг 5. Настрой postback в партнёрской системе
Укажи в партнёрке адрес вида:
```
http://АДРЕС_СЕРВЕРА:8000/postback?ref_id={ID_РЕФЕРАЛА}&status={СТАТУС}
```
Названия полей зависят от партнёрской системы. Проверка вручную — открой в браузере:
```
http://АДРЕС_СЕРВЕРА:8000/postback?ref_id=ВАШ_КОД&status=1
```
Если вы заходили в бота по ссылке с этим кодом — придёт приглашение.

## Команды бота

| Команда | Кто | Что делает |
|---|---|---|
| `/start <код>` | гость (по ссылке) | запоминает пару «код ↔ пользователь» |
| `/setgroup` | админ, в группе | запоминает целевую группу |
| `/grant <код>` | админ, в личке | выдать доступ вручную |
| `/help` | гость | как это работает |

## Работа 24/7 (VPS)

Боту нужен постоянно включённый сервер (VPS, от ~200 ₽/мес):
```bash
sudo apt update && sudo apt install -y python3-pip python3-venv
cd telegram-referal-bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
nohup python3 bot.py > bot.log 2>&1 &
```
Лог: `tail -f bot.log`.
